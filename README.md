# Campus Waste Management Analytics

## Business Analytics Project (DSC3132)

### Project Description

This project focuses on analyzing campus waste data to identify waste generation patterns, major waste categories, and important trends. The aim is to generate data-driven insights that can help improve waste management and support better decision-making on campus.

### Objectives

- Analyze campus waste generation patterns.
- Identify major types and sources of waste.
- Visualize waste-related trends and patterns.
- Generate meaningful business insights.
- Provide recommendations for better waste management.

### Methodology

1. Data Collection
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis
4. Data Visualization
5. Trend & Pattern Analysis
6. Business Insights
7. Recommendations

### Tools Used

- R
- R Markdown
- HTML
- CSV Dataset
- GitHub

### Project Files

- `Business_Analytics_Project.Rmd` – Complete analysis
- `Business_Analytics_Project.html` – Analysis report
- `Campus_Waste_Dataset.csv` – Dataset
- `README.md` – Project documentation

### Expected Outcome

The project aims to provide data-driven insights into campus waste generation and help identify opportunities for improved waste collection, segregation, resource allocation, and sustainable campus management.

### Conclusion

This project demonstrates how Business Analytics can transform campus waste data into meaningful insights and support better, data-driven decisions.
